# تطبيق "مِشكاتي" 🇵🇸 (Mishkati)
> **«مِشكاتي: نور يومك وعون دراستك»**  
> *Mishkati: Illuminating your day, empowering your studies.*

تطبيق وب إسلامي حديث وأكاديمي متكامل لطلاب وطالبات فلسطين في الوطن والشتات. يجمع بين **مواقيت الصلاة الحية الدائمة المثبتة** مع عداد تنازلي نشط، و**درج تنقل ذكي للأذكار**، و**نظام تسجيل الدخول وحساب الطالب**، و**بنك أدعيتي الخاصة التفاعلي**.

---

## 🌟 التحديثات المعمارية الكبرى الجديدة:

### 1. مكان الصلاة الثابت الدائم (Persistent / Pinned Prayer Times Widget):
- **الموقع الثابت**: شريط علوي مثبت (`Sticky Top Bar`) يظل ظاهراً بشكل دائم ومستمر أثناء التمرير في كافة صفحات وأقسام التطبيق دون أن يحجب المحتوى.
- **الحالة المضغوطة (Compact State)**:
  - اسم المدينة الفلسطينية الحالية (مثال: القدس الشريف، غزة، نابلس...).
  - اسم الصلاة القادمة ووقتها.
  - عداد تنازلي حي بالثواني (`HH:MM:SS`) للوقت المتبقي لرفع الأذان.
  - مؤشر نسبة الانقضاء الزمني.
  - زر طي وتوسيع تفاصيل الصلوات.
- **الحالة الموسعة (Expanded State)**:
  - عند النقر على الزر، ينسدل كرت مصغر يضم أوقات الصلوات الخمس كاملة + الشروق، مع التاريخ الهجري والميلادي، واتجاه القبلة، وزر تحديد الموقع الفوري في فلسطين.

### 2. قائمة الأذكار ودرج التنقل (Dedicated Navigation Drawer):
- **قائمة جانبية سريعة وسلسة (Off-canvas Drawer)** تُفتح بضغطة زر وتعمل بمرونة تامة على الهواتف والأجهزة المكتبية:
  1. ☀️ **أذكار الصباح** (19 ذكراً مع شارة التقدم).
  2. 🌙 **أذكار المساء** (17 ذكراً مع شارة التقدم).
  3. 🕌 **أذكار بعد الصلاة** (الاستغفار، التسبيح والتحميد والتكبير 33، آية الكرسي والمعوذات).
  4. 🤲 **أدعيتي الخاصة** (بنك الأدعية المخصصة للطالب مع عداد الردود).
  5. 🎓 **أدعية المذاكرة والامتحانات** (الفهم، تيسير الصعب، انشراح الصدر، تثبيت الحفظ).
  6. 📿 **المسبحة الإلكترونية الذكية** (مع أهداف 33 / 100 / 500 / 1000).
- تنقل فوري بدون إعادة تحميل الصفحة مع الحفاظ التام على حالة العدادات ونسبة التقدم.

### 3. نظام تسجيل الدخول وحساب الطالب (User Authentication System):
- **تسجيل الدخول وإنشاء حساب**:
  - بالبريد الإلكتروني وكلمة المرور.
  - الدخول السريع عبر Google (`Google OAuth`).
  - دخول تجريبي بنقرة واحدة كطالب فلسطيني متميز.
- **وضع الزائر (Guest Mode)**:
  - يمكن للزائر استخدام مواقيت الصلاة والأذكار والمسبحة دون الحاجة لحساب، مع حفظ التفضيلات محلياً ودعوة لطيفة للتسجيل لمزامنة أدعيته عبر الأجهزة.
- **ملف المستخدم في الترويسة**:
  - عرض اسم وصورة/شارة المستخدم في أعلى الصفحة مع قائمة منسدلة تضم الوصول لأدعيته الخاصة وتسجيل الخروج.

### 4. بنك أدعيتي الخاصة وحاجاتي (Custom User Duas Feature):
- واحة مخصصة للطلبة لكتابة وإدارة أدعيتهم الشخصية:
  - **نافذة "أضف دعاء جديد"**:
    - عنوان أو مناسبة الدعاء (امتحان التوجيهي، تفريج هم، للوالدين، شفاء...).
    - نص الدعاء الكامل (دعم النصوص الطويلة والتشكيل).
    - عدد مرات التكرار المطلوبة (1، 3، 7، 10، 33، 100).
    - التصنيف (دراسة وامتحانات، تفريج كرب، رزق وتوفيق، حفظ وعافية، لأهل فلسطين، عام).
  - **كرت الدعاء التفاعلي**:
    - نفس آلية النقر التنازلي التفاعلية (مثلاً: 3 -> 2 -> 1 -> 0).
    - حالة الإنجاز المميزة بلون عنبري زمردي ورنين بلوري لطيف واهتزاز للهاتف.
    - خيارات تعديل، حذف، تفضيل بالرمز (⭐) لتثبيت الأدعية الهامة في المقدمة، ونسخ ومشاركة.
  - **حفظ متكامل**: حفظ فوري ومحلي في `mishkati_custom_duas` مع دعم كامل للمزامنة السحابية.
